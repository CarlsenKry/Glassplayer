KRYPTON PLAYER — CI TOOLCHAIN UPDATE

What changed in this archive:

1. Replaced the legacy Android SDK setup action usage with
   android-actions/setup-android@v4.
2. Explicitly requested only platform-tools from the setup action. The workflow
   never requests the removed SDK package named "tools".
3. Let setup-android install its current command-line tools, then installed
   platforms;android-36 and build-tools;36.0.0 with sdkmanager.
4. Updated the other GitHub Actions to current major releases:
   actions/checkout@v7, actions/setup-java@v6,
   gradle/actions/setup-gradle@v6, actions/upload-artifact@v7.
5. Pinned CI to JDK 17 and Gradle 8.14.7. CI invokes the Gradle installation
   directly because this project uses lightweight gradlew bootstrap scripts,
   not the standard Gradle Wrapper JAR.
6. Added toolchain verification and uploads build reports/test results even
   after a build failure, so later errors are easier to diagnose.
7. Updated scripts/selfcheck.py to validate the new CI configuration.

Validation performed for this archive:

- GitHub Actions YAML parsed successfully.
- No APK compilation is claimed. This environment could not download the

BUILD FIX (follow-up to the failed run "Verify and build APK")

Failure in the log: app/build.gradle.kts line 45
  "Using 'jvmTarget: String' is an error. Please migrate to the compilerOptions DSL"
Cause: Kotlin 2.4 removed android { kotlinOptions { } }.

Fixed:
1. app/build.gradle.kts: JVM target now set in a TOP-LEVEL kotlin { compilerOptions { } }
   block (the previous attempt nested it inside android { }).
2. Toolchain made self-consistent. AGP 8.13.2 + compileSdk 36 cannot consume the
   newest AndroidX (core 1.19, activity 1.13, lifecycle 2.11, hilt-navigation-compose
   1.4, Compose BOM 2026.08+), which need AGP 9.x / compileSdk 37. Pinned to:
   Kotlin 2.3.21, KSP 2.3.6, Compose BOM 2026.06.01, core-ktx 1.18.0,
   activity-compose 1.12.4, lifecycle 2.10.0, datastore 1.2.1,
   androidx.hilt:hilt-lifecycle-viewmodel-compose 1.3.0 (navigation-compose removed:
   it was unused).
3. Hilt 2.57.2 + new Kotlin metadata: kotlin-metadata-jvm is forced to 2.3.21 in
   app/build.gradle.kts (Dagger has no release that reads Kotlin 2.4 metadata yet).
4. LibraryScreen: PaddingValues(horizontal=, bottom=) is not a valid overload.
5. PlaybackViewModel: Context.mainExecutor needs API 28 (minSdk is 26) -> ContextCompat;
   removed a stray @UnstableApi that would have failed lint at every call site.
6. Deprecated non-mirrored icons replaced by Icons.AutoMirrored.*.
7. values-fr: unescaped apostrophe (l'accès) fixed.
8. MediaLibraryRepository: stale-track cleanup now deletes in chunks of 500
   (a single NOT IN (...) with thousands of ids can exceed SQLite's variable limit).
9. CI: unit tests + assembleDebug are blocking; lint runs as a separate non-blocking
   step. gradlew is now executable in git.
No local compilation was possible (no network/Gradle in the authoring sandbox).
